## Reading these three results honestly

The 0/3 raw answer-generation number is misleading taken at face value -- checked by
hand, not just reported:

- **Page 13**: agent generated "496 sq ft" against a key of "496 ft²" -- the same
  value, "sq ft" vs "ft²" notation. This script's scoring reuses
  `k12ta.grading.key_grader.normalise`, which does not know these two unit phrasings
  are the same string, so it counts as a mismatch. Read by a person, this generation
  is correct.
- **Page 15**: the two independent solves disagreed (`agreement gating` correctly
  produced `needs_human`, confidence still reported as 1.0 on each individual call --
  see the open note below), so there is no consensus `generated_answer` to score at
  all -- not a wrong answer, an honest "could not independently verify." This is a
  spatial/visual question ("what shape is created by each cross section") that a
  text-only call has no real way to solve without seeing the actual solid -- exactly
  the class of case tier 3 (vision, not built yet) exists for, not a defect in tier 2.
- **Page 17**: agent generated "0.475 cups (or 19/40 cups)" -- arithmetically correct
  (4.75 / 10 = 19/40 = 0.475, checked by hand). The stored key text, "1 19/40 cups of
  broth per serving", evaluates to 1.475, not 0.475 -- **the key on file for this
  problem appears to have a real typo** (an extra leading "1 "), independent of
  anything the evaluator did. Worth a parent double-checking this specific key entry;
  not a finding about the evaluator's accuracy.

Once naive string mismatches and the one genuinely-flawed key are set aside, the
evaluator's own generated answers were arithmetically right on the two pages it
reached a verdict on at all, and correctly declined to guess on the one it
legitimately could not solve from text alone. Three pages is nowhere near enough to
say more than that -- this is exactly why it's a smoke test, not a calibration
number.

**Open note on confidence:** every call reported `confidence: 1.0`, including the
one that disagreed with its own independent partner and the one with no image access
to a spatial problem. `prompts/evaluate_text.md` asks the model to report low
confidence when genuinely unsure, but three real calls all returning a flat 1.0
suggests the model is not actually modulating this value the way the prompt asks --
worth watching once a larger run exists; not something three data points can
diagnose.

**Do not read this as evidence the keyless path is safe for RSM.** Summer Bridge has clean, well-structured printed answers; RSM Pre-Algebra Advanced is where this path's real exposure is.
